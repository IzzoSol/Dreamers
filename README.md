# Dreamers

A Web3 gaming ecosystem built by Izzo on Solana, featuring the tower climbing game **Dreamers Climb**, a $DREAM token economy, NFT system, DAO governance, marketplace, and artist showcase. Powered by the SHADDAI 7-Agent System.

## 🎮 Dreamers Climb — Tower Climbing Game

A pixel-art tower climbing game with FOMO collection mechanics. Play as The Boy, The Girl, or The Robot as you climb towers, collect items, fight bosses, and unlock new biomes.

- **Latest build:** `game/dreamers-climb-v31.0.html` (fixed)
- **Full version:** `game/dreamers-climb-v28.88.html` (Ultimate Edition with Web3)
- **Versions:** 5.0 → v31.0+ documented
- **Play:** Open any HTML file in a browser

[→ See game changelog](game/CHANGELOG.md)

## 💎 Ecosystem Components

| Component | Description |
|-----------|-------------|
| **$DREAM Token** | Solana SPL token with 6% transaction tax (2% burn, 2% treasury, 1% rewards, 1% dev) |
| **NFT System** | Character skins, music, art, achievements, event NFTs (Metaplex on Solana) |
| **DAO Governance** | $DREAM holders vote on treasury spending, features, partnerships |
| **Marketplace** | Buy/sell digital goods, physical merch, services — all priced in $DREAM |
| **Artist Showcase** | Platform for independent creators to mint and sell work |
| **7 Agents** | SHADDAI, ZEROX, ORACLE, NEXUS, TURTLE, QUILL, PIKADON — 380+ skills total |
