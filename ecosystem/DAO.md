# Dreamers DAO

Decentralized governance for the Dreamers Ecosystem treasury. $DREAM holders vote on how funds are spent.

## Governance Structure

- **Voting power:** Proportional to $DREAM holdings
- **Proposal threshold:** Minimum $DREAM to submit
- **Voting period:** 3-7 days per proposal
- **Quorum:** 10% of circulating supply must vote
- **Execution:** Multi-sig treasury (Izzo + 2 trusted community members)

## What The DAO Votes On

- Treasury spending (development, marketing, events)
- Featured artist selections
- Game feature priorities
- Special burn events
- Partnership approvals
- Season themes and rewards
- Community grants

## What The DAO Does NOT Control

- Core token economics (tax %, burn %)
- Dev wallet allocation
- Security decisions
- Smart contract upgrades (admin retained)

## Treasury Sources

- 2% tax from every $DREAM transaction
- NFT minting fees (treasury portion)
- Marketplace fees (treasury portion)
- Partnership revenue

## Implementation Phases

| Phase | Tool | Description |
|-------|------|-------------|
| Phase 1 (MVP) | Snapshot | Off-chain voting, gas-free |
| Phase 2 | Realms | Solana-native DAO framework |
| Phase 3 | On-chain program | Full execution via smart contract |
