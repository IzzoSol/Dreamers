# Dreamers Token Economy — $DREAM

**Chain:** Solana (SPL Token)
**Name:** $DREAM
**Supply Model:** Fixed supply with deflationary burn mechanics
**Status:** Planning (devnet → mainnet)

## Tax System (Per Transaction)

| Destination | % | Purpose |
|-------------|---|---------|
| Burn | 2% | Permanent deflation |
| Treasury | 2% | Development, ops, artist payouts |
| Rewards Pool | 1% | Redistributed to holders/players |
| Dev Wallet | 1% | Creator revenue |
| **Total** | **6%** | |

## Token Utility

| Use Case | How |
|----------|-----|
| In-game currency | Earn from gameplay (coins, bosses, achievements) |
| NFT purchases | Character skins, music NFTs, art NFTs |
| Marketplace payments | Merch, consulting, digital goods |
| Staking | Lock tokens for yield from rewards pool |
| Governance | Vote on DAO proposals (weighted by holdings) |
| Artist tips | Direct support to showcase artists |
| Tournament entry | Pay to enter competitive events |

## Earn Paths

1. **Gameplay rewards** — coins collected in Dreamers Climb convert to $DREAM
2. **Achievement bonuses** — milestones (first 1000m, first boss kill)
3. **Leaderboard prizes** — weekly/monthly top players
4. **Referrals** — bring new players, earn % of first-week activity
5. **Staking yield** — lock $DREAM, earn from rewards pool

## Burn Mechanics

- 2% of every transaction burned permanently
- Special burn events via DAO vote
- NFT minting burns set amount of $DREAM
- Tournament entry fees partially burned
- Seasonal events with bonus burn rates
